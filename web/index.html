Combinatorial Game Theory (CGT)

This is a web-based demo of my final bachelor thesis. The main subject of the work was a C library compiled for this demo using webAssembly that calculates short games. The term short game is a less well-known term and more people know these numbers under the term "surreal numbers", although it is technically incorrect in this context.

Available Modules

  • Hotpotch: A colored-edge game with blue, red, green edges and gravity.
  • Domineering: Vertical and horizontal domino placement.
  • Toads & Frogs: Toads move right and frogs move left.
  • Calculator: Parse and evaluate a short-game expression.
  • JS Sandbox: Write custom game rules in JavaScript using the JavaScript interface

The project includes, among other things, Python and JavaScript wrappers for the C library. I found the Python library more interesting to work on, so it is more fully developed; the relevant files—`game.py` and `game_runtime.py`—can be found at .
